# PyPassword Generator

A simple Python program that generates random, secure passwords with letters, numbers, and symbols.

---

## Features

- Lets you choose the number of letters, symbols, and numbers in your password.
- Randomizes the order of characters for stronger security.
- Easy to use and lightweight.

---
